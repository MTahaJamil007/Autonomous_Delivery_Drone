# Exact Python package versions of the reference machine (the laptop this
# project was developed and verified on): Ubuntu 22.04.5, Python 3.10.12,
# pip 22.0.2, ROS 2 Humble, Gazebo Harmonic, PX4 main @ 4a48525e45.
#
# This is a pip CONSTRAINTS file, not a requirements file: it installs nothing
# by itself, it only fixes the version of anything that something else asks
# for. Use it for BOTH of the pip installs on a new machine, so that PX4's
# unpinned requirements and this project's ranges resolve exactly as here:
#
#     PIP_CONSTRAINT=$HOME/DroneProgram/constraints/py310-lock.txt bash Tools/setup/ubuntu.sh
#     PIP_CONSTRAINT=$HOME/DroneProgram/constraints/py310-lock.txt make install
#
# Scope: the full dependency closure of PX4's Tools/setup/requirements.txt,
# this project's pyproject.toml (including [dev]) and the Makefile's
# setuptools pin - restricted to the packages pip installed into ~/.local.
#
# NOT listed here, on purpose:
#   - Packages Ubuntu's apt provides and pip leaves alone because they already
#     satisfy every requirement: empy 3.3.4, idna 3.3, iniconfig 1.1.1,
#     pillow 9.0.1, pygments 2.11.2, pytz 2022.1, pyyaml 5.4.1, six 1.16.0,
#     toml 0.10.2, urllib3 1.26.5, wheel 0.37.1. They arrive with
#     ros-humble-desktop, colcon and python3-pip, and scripts/verify_env.sh
#     checks their versions. (Pinning them here would make pip fetch pyyaml
#     5.4.1 from PyPI if apt had not, and that sdist no longer builds.)
#   - gz.transport13 / gz.msgs10 and rclpy: apt only, not on PyPI.
#   - Packages in ~/.local that belong to other projects and nothing here
#     imports (Flask, google-genai, PyAudio and their dependencies).
#
# The two pins that matter most:
#   protobuf==3.20.1  gz.msgs10 fails to import on protobuf 4+. Without this
#                     file it is held at 3.20.x only because mavsdk 2.8.4
#                     happens to cap it (protobuf<=3.20.1).
#   mavsdk==2.8.4     Battery.remaining_percent is 0-100 in 2.x, 0-1 in 1.x.
#
# Regenerate only deliberately, and re-run `make check` and
# scripts/verify_env.sh afterwards.
#
# Proved on 28 Sep 2026 with pip 22.0.2: a download-only run of PX4's
# requirements plus this project's, constrained by this file, fetched from PyPI
# and resolved all 77 pins exactly; installing those files into an empty user

# `make check` 199 passed.
